# UE 5.8 release notes, condensed by area

Condensed on 2026-11-12 from the "Release Notes" part of Epic's "Unreal Engine 5.8 Release Notes" (<https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-5-8-release-notes?application_version=5.8>): every area, including the bug-fix lists, reduced to the items that name an API, console variable, setting, plugin or changed behaviour. Each group of areas was condensed separately, so wording varies between areas, and identifiers are as the notes spell them, misspellings included. Fixes that only said a crash or glitch was fixed were dropped.

Search this file for a class, function, console variable or feature name; it is too long to read whole. Confirm a name in the installed engine before relying on it: of the 404 class, struct and enum names here, 381 were found in the 5.9 headers; the other 23 are mostly the old half of a rename, removed or private types, or the notes' own misspellings. The changes most likely to break code are summarised, and partly checked on disk, in [`features-5.8.md`](features-5.8.md).
